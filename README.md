# Kira Gor — Epidemiology and Healthcare Analytics Portfolio

Live site: **[gorkira28.github.io](https://gorkira28.github.io/)**

This repository contains the professional portfolio of **Kira Gor, BDS, MPH**, a clinician-trained epidemiologist and healthcare data analyst. The site presents selected analytics projects, peer-reviewed research, professional experience, environmental-health recognition, and contact information in a recruiter-friendly format.

## Featured analytics work

- [Pertussis Surveillance Priorities](https://github.com/gorkira28/pertussis-2025-surveillance-priorities) — DuckDB SQL, QGIS, surveillance epidemiology, and QA/QC
- [Hidden Hypertension: NHANES Awareness-Gap Analysis](https://github.com/gorkira28/nhanes-hypertension-awareness-gap) — SAS, Python, complex-survey analysis, and sensitivity checks
- [Texas Diabetes Vulnerability Atlas](https://github.com/gorkira28/texas-diabetes-vulnerability-atlas) — Python, SAS, GIS, CDC PLACES, and spatial analysis

## Site structure

- `index.html` — accessible single-page portfolio
- `style.css` — responsive visual system
- `app.js` — interactive methods demonstration
- `privacy-controls.js` and `privacy.html` — consent and privacy controls
- `contact-form.js` and `site-config.js` — recruiter contact workflow
- `assets/` — portfolio images and analytical visuals

## Local preview

Serve the repository root with any static web server. For example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Content standards

Portfolio claims link to public evidence where practical. Analytical projects use public data, explain limitations, distinguish descriptive findings from causal conclusions, and exclude PHI, confidential employer information, and proprietary Texas DSHS material.
